# Login Form

A clean, responsive login form built using HTML, CSS, and JavaScript.

![Login Form Screenshot](./Screenshot%202024-09-24%20141659.png)

## Overview

This repository contains a simple, accessible login form layout intended as a small front-end project / UI component. It's easy to customize and drop into any static site or prototype.

## Features

- Modern, clean UI built with HTML & CSS
- Basic client-side validation using JavaScript
- Responsive layout that adapts to different screen sizes
- Ready-to-use: open `index.html` to preview

## Technologies

- HTML
- CSS
- JavaScript

## Files

- `index.html` — main page containing the login form
- `style.css` — styles for layout and visual design
- `Screenshot 2024-09-24 141659.png` — demo screenshot used in this README
- `castle.png` — extra image asset included in the repo

## How to run

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Login-Form-115.git

2. Open the project folder and launch `index.html` in your browser:

   - Double-click `index.html`, or
   - Serve the folder with a static server (recommended for some browsers):
     - `npx http-server` (Node.js) or `python -m http.server`

## Customize

- Edit `style.css` to change colors, spacing, or fonts.
- Update `index.html` to add or remove fields.
- Add stronger validation or connect the form to a backend by replacing the placeholder JavaScript with real API calls.
